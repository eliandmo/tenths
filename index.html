A museum doorway is 1710 meters high.

How can you represent that height with tenths models and as a decimal?

💡 Before we start — think for a moment: The number 1710 is called a mixed number. It has a whole part (1) and a fraction part (7/10). Today we'll learn how to show it with a model AND write it as a decimal!

📖 Part B — Read & Write

Read the Number, Write the Decimal

Let's break apart 1710 and write it as a decimal — step by step.

Step 1 — Say the number aloud:
1710 is read as "one and seven tenths."

🔑 The word "and" shows where to write the decimal point!

"one" and "seven tenths"
1 · 7
Step 2 — Write the parts:
"One" is written as 1  ·  "Seven tenths" is written as 0.7
1 710 = 1 . 7 = 1.7

The decimal is 1.7 ✓
